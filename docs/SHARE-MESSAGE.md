# Message to send with the ZIP

Here's an independent copy of the LFG bot. You can create your own Discord application, give it your own name/avatar, and change the code however you like under the included MIT license.

Start with README.md, then docs/OWN-COPY.md. Install Node.js 24.17+, put your own bot token in .env, run setup.cmd and then start.cmd on Windows (or npm run setup and npm start on other systems). Setup gives you the invite link for your own bot. In your server, run /lfg-setup to choose the game and settings.

You'll need to keep the bot running on a computer or host for it to stay online. Your token and server data stay with your copy. Please keep the included license notice if you redistribute the code.
